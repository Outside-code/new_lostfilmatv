# Проверка загрузки 22 ноября 2026

Проверены реальные HTTP GET с компьютера разработчика и с сервера auth bridge. Это замеры из двух сетей, а не гарантия доступности у любого провайдера.

| Оригинальный фон через свой сервер | 1.27 | 0.03 | HTTP 200, JPEG 3 747 817 байт |

В приложении сохранён основной адрес `https://www.lostfilm.today`. Для изображений используется собственный сервер, затем резервный прокси и TMDB CDN. Старые сохранённые ссылки на изображения тоже проходят через эту схему.

Маленькие миниатюры LostFilm не растягиваются: карточки ждут постеры TMDB, а полноэкранный фон использует только широкое фоновое изображение. Для фоновых изображений запрашиваются оригиналы, декодирование ограничено разрешением экрана до 4K, искусственное размытие отключено. Затемнение главного фона — равномерные 15%, без локальных прямоугольных подложек и градиентов.

Проверены создание QR-сессии, открытие телефонной страницы входа, переход в `in_progress`, отмена и доступность брендовых ресурсов в установленном wheel-пакете. Владелец завершил вход на телефоне и подтвердил успешный вход на физическом Google TV. Ложная ошибка сети на телефонной странице после успешного входа устранена: AJAX-ответ нормализован в JSON, повторная отправка не запускает вход заново. Регрессионный сценарий и остальные 134 теста сервера проходят.
